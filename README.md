# pritishbudhiraja.com

Personal site of [Pritish Budhiraja](https://www.pritishbudhiraja.com), Senior Software Engineer.

Next.js, TypeScript, Tailwind CSS, and [Hatch](https://ui.pritishbudhiraja.com) (`@pritish.budhiraja/ui`).

## Develop

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

| Script | What it does |
| --- | --- |
| `pnpm dev` | Development server |
| `pnpm build` | Production build |
| `pnpm lint` | Biome and TypeScript |
| `pnpm knip` | Unused export check |
